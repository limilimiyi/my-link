# 🎨 와이어프레임 & UI 시각 설계 (Wireframes & UI Layout): 마이링크

> [!NOTE]
> 본 문서는 마이링크(MyLink)의 주요 화면 레이아웃과 컴포넌트 배치를 다루는 와이어프레임 명세서입니다. 
> 
> 채용 담당자가 편안하게 정보를 검토할 수 있도록 불필요한 화려한 빛 효과나 그라데이션을 배제하고, **극도로 깔끔하고 가독성 높은 미니멀 화이트(Minimal White) 디자인 시안**을 최종 기본 스펙으로 채택했습니다.

### 1.2 화면 레이아웃 및 구성 요소
* **배경 (Background):**
  * 시각적 피로를 줄여주고 가독성을 최대화하는 솔리드 소프트 라이트 그레이(`#F8F9FA`) 단색 배경. (빛 번짐이나 빔 효과 완전히 배제)
* **프로필 헤더 영역:**
  * **아바타(Avatar):** 중앙에 원형으로 배치된 정갈한 개발자 이모지(🧑‍💻 또는 구글 프로필 사진). 우측 하단에 부드럽게 깜빡이는 차분한 초록색 **온라인 상태 배지** 부착.
  * **닉네임:** 가독성이 뛰어난 산세리프(Sans-serif) 계열의 다크 슬레이트 톤 타이틀 (`이림_개발자`).
  * **소개글(Bio):** 서브 타이틀 형태의 명확한 회색 톤 한 줄 소개글 (`Frontend Developer`).

* **링크 카드 리스트 (Link Cards):**
  * 얇고 차분한 밝은 회색 테두리(`border: 1px solid #E5E7EB`)를 지닌 플랫한 화이트 둥근 모서리 카드 버튼들.
  * **파비콘 자동 추출 아이콘:** 개별 카드의 왼쪽에는 해당 도메인의 오리지널 파비콘(Notion, GitHub 등)이 크기에 알맞게 자동 매핑되어 노출됨.
  * **우측 이동 인디케이터:** 깔끔하고 절제된 모양의 쉐브론 화살표(`>`)가 위치하여 깔끔한 유입을 유도.

## 2. 관리자 대시보드 페이지 (Admin Dashboard)

소유자(Owner)가 구글 로그인 후 진입하여 본인의 프로필 및 링크를 관리하는 심플한 데스크톱/태블릿 맞춤형 입력 폼 레이아웃입니다.

```text
+-----------------------------------------------------------------------------+
|  [MyLink Admin]                                                [로그아웃]   |
+-----------------------------------------------------------------------------+
|                                                                             |
|  ■ 1. 내 프로필 설정 (인라인 편집 지원)                                     |
|  +-----------------------------------------------------------------------+  |
|  |  ( 🧑‍💻 )  구글 아바타 연동 (또는 이모지 선택 가능)                        |
|  |                                                                       |  |
|  |  * 닉네임 (클릭해서 바로 수정):                                       |  |
|  |  [ 이림_개발자                                                     ]  |  |
|  |  └─ 실시간 생성 URL: https://mylink.com/이림_개발자                   |  |
|  |                                                                       |  |
|  |  * 한 줄 소개 (클릭해서 바로 수정):                                   |  |
|  |  [ React와 TypeScript를 좋아하는 프론트엔드 신입 개발자입니다.       ]  |  |
|  +-----------------------------------------------------------------------+  |
|                                                                             |
|  ■ 2. 포트폴리오 링크 관리 (인라인 편집 지원)                               |
|  +-----------------------------------------------------------------------+  |
|  |  [➕ 새 링크 추가]                                                     |  |
|  |                                                                       |  |
|  |  [파비콘]  [ GitHub 저장소        ] ✎   [ https://github.com/limi... ] ✎  [🗑] |
|  |  [파비콘]  [ Notion 포트폴리오    ] ✎   [ https://notion.so/limili... ] ✎  [🗑] |
|  +-----------------------------------------------------------------------+  |
|                                                                             |
|  ■ 3. 테마 선택 프리셋                                                      |
|  +-----------------------------------------------------------------------+  |
|  |  [ Minimal White (선택됨 ●) ]     [ Slate Tech ( ) ]     [ Dark Flat ( ) ]|
|  +-----------------------------------------------------------------------+  |
|                                                                             |
|  ■ 4. 내 프로필 공유 및 홍보                                                |
|  +-----------------------------------------------------------------------+  |
|  |  [ 🔗 전체 URL 복사 ]                [ 📱 QR 코드 생성 팝업 ]             |
|  +-----------------------------------------------------------------------+  |
|                                                                             |
+-----------------------------------------------------------------------------+
```

### 2.1 대시보드 핵심 기능 구성
* **인라인 텍스트 입력 필드:**
  * 닉네임, 소개글, 링크 제목, 링크 URL 옆의 편집 아이콘(`✎`)을 누르거나 텍스트를 클릭하면 즉시 입력 폼으로 전환되며, 포커스를 잃거나 엔터를 치면 즉시 자동 저장 및 파비콘 갱신이 이루어집니다.
* **파비콘 자동 로드:**
  * 링크 URL 란에 주소를 입력하고 입력창을 벗어나면, 시스템이 주소를 분석하여 실시간으로 해당 사이트의 오리지널 파비콘을 로드해 보여줍니다.
